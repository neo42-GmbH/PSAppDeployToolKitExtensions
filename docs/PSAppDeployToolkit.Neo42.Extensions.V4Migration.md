# Migration Guide to V4 Packaging

This guide will present migration solutions for neo42 Extension variables and functions that have been changed from the migration to V4.
These changes are in addition to the changes documented by PSADT [here](https://psappdeploytoolkit.com/docs/4.1.x/getting-started/upgrade-guidance-v3x-to-v41).

## Variables

Note that all variables that previously required the `global:`-scope prefix, now do not require it anymore. The use of globally scoped variables is now highly discouraged to prevent mixing script and module environment. It was only needed due to V3 architecture.

All variables exposed by the toolkit are now available in the scope of the deployment script.

### Package Architecture Variables

Application specific architecture variables have been removed.
The desired directory should be determinable without these helpers. You can find recommendations below.

| Variable           | Migration                                                                                                                                             |
| :----------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------- |
| ProgramFilesDir    | Use `envProgramFiles` for the 64-bit directory.                                                                                                       |
| ProgramFilesDirx86 | Use `envProgramFilesW3264` to always use the OS native 32-bit directory.                                                                              |
| ProgramW6432       | Use `envProgramFilesW3264`, its value is guaranteed to not be empty.                                                                                  |
| CommonFilesDir     | Use `envCommonProgramFiles` for the 64-bit directory.                                                                                                 |
| CommonFilesDirx86  | Use `envCommonProgramFilesW3264` to always use the OS native 32-bit directory.                                                                        |
| CommonProgramW6432 | Use `envCommonProgramFilesW3264`, its value is guaranteed to not be empty.                                                                            |
| System             | Use either `envSystemX64` or `envSystemX86` for process architecture independent `System32` access.                                                   |
| Wow6432Node        | The content of this variable is now dependent on process and operating system dependent architecture.                                                 |
| RegSoftwarePath    | Use `envRegistrySoftware` for the 64-bit registry path. Note that there is no built-in way to access a 64-bit registry from a 32-bit process by path. |
| RegSoftwarePathx86 | Use `envRegistrySoftwareW3264` for the 32-bit registry path.                                                                                          |

### Deployment Variables

In the same sense as PSADTv4 deployment variables have been moved to the deployment session,
all extension variables have been moved into the `NXT` session extension property.

| Variable                         | Migration                                                                                                                   |
| :------------------------------- | :-------------------------------------------------------------------------------------------------------------------------- |
| CustomSetupCfg                   | This variable has been dropped.                                                                                             |
| DeploymentTimestamp              | This variable behaves the same as in V3.                                                                                    |
| RegisterPackage                  | The variable now resides in `$adtSession.NXT.Package.Register`                                                              |
| SetupCfg                         | This variable now resides in `$adtSession.NXT.SetupCfg`. It is now its own `NxtIniDocument` type.                           |
| PackageConfig                    | Dropped due to the package config no longer being exposed directly, but rather APIs are exposed in the session object.      |
| Neo42PackageConfigValidationPath | Validation is now handled within the the C# model. For legacy validation use the included `neo42PackageConfig.schema.json`. |
| SetupCfgPath                     | The path is now set as parameter in `New-NXTSessionParameter`. The variable is no longer exposed.                           |
| CustomSetupCfgPath               | The path is now set as parameter in `New-NXTSessionParameter`. The variable is no longer exposed.                           |
| DeployApplicationPath            | This variable was superfluous, use `$PSCommandPath` instead.                                                                |
| AppDeployToolkitExtensionsPath   | Due to the drop of V3 files, this is no longer needed.                                                                      |
| AppDeployToolkitConfigPath       | Due to the drop of V3 files, this is no longer needed.                                                                      |
| DeploymentSystem                 | This variable now resides in `$adtSession.NXT.DeploymentSystem`.                                                            |
| UserPartDir                      | UserPartDir is now reflected in the value of `$adtSession.DirSupportFiles` automatically.                                   |
